# OperationInAI 使用文档

## 启动

```powershell
npm.cmd run dev
```

访问：

```text
http://localhost:4173/
```

## 推荐使用顺序

1. 在“数据清洗 / 支持配置库”中维护认证配置和清洗规则。
2. 在“数据清洗 / 数据源配置”中维护 API、数据库或文件数据源。
3. 在同页配置字段映射，必要时点击“测试联通”从响应体选择字段。
4. 在“数据清洗 / 业务配置”中为业务编排唯一业务流。
5. 在“数据展示”中选择业务和时间范围查看业务数据。
6. 在“智能分析”中配置模型，选择业务和字段生成分析。
7. 在“智能搜索”中维护知识源并提问。

## 数据清洗

### 认证配置

当前默认支持通用无认证、API Cookie、数据库账号密码三类配置。数据源只引用认证名称，Cookie 或账号细节在认证配置中维护。

### 数据源配置

数据源支持：

- API：配置 URL、方法、Query/Header/Body、分页字段和响应路径。
- 数据库：配置表名或查询目标，后续可扩展为真实连接配置。
- 本地文件：配置文件路径。

入参来源支持固定入参、数据库查询、上游数据源和业务流上下文。逐条调用或批量调用由“调用方式”控制。

API 数据源的“测试联通”规则：

- 当数据源地址是完整 `http://` 或 `https://` URL 时，后端会发起真实请求。
- 当地址是相对路径、表名或文件名时，系统使用模拟响应辅助字段映射配置。
- 测试结果会标明“真实请求”或“模拟响应”，并展示响应字段、样本记录数和响应体。

请求入参会根据请求方法自动调整：

- `GET`、`DELETE`、`HEAD`：展示 Query 和 Header，隐藏 Body。
- `POST`、`PUT`、`PATCH`：展示 Query、Header 和 Body。

入参来源使用方式：

- 固定入参：直接填写 Query/Header/Body。
- 数据库查询：选择数据库来源，勾选字段后可生成 SQL 和字段映射。
- 上游数据源：选择上游数据源，系统根据该数据源字段映射或样例字段提供候选字段。
- 业务流上下文：使用 `context.start_time`、`context.end_time`、`context.businessName` 等上下文字段驱动调用。

勾选“来源字段”后点击“生成入参与过滤”，系统会自动生成入参字段映射 JSON 和建议过滤条件，用户再按实际接口调整即可。

### 字段映射

字段映射用于把源字段转换为目标业务字段。可以配置：

- 响应数据路径。
- 保留全部记录或按条件过滤。
- 源字段、目标字段、字段类型、默认值。
- 可选清洗规则和规则参数。
- 字段保留策略：保留全部字段，或只保留测试响应中勾选的字段。
- 存储策略：不单独存储，或存储到原始表、清洗表、指定表。

### 业务流

一个业务对应一个业务流。业务流节点可表示：

- 上下文节点：时间窗口、租户、批次号。
- 数据源节点：采集 API、数据库或文件数据。
- 规则节点：清洗、映射、关联补齐。
- 输出节点：写入原始表、清洗表和业务表。

节点支持串行、并行、条件分支和汇聚。

## 数据展示

选择业务模型后，可以使用：

- 时间字段：用于指定业务数据中的时间匹配字段。
- 时间预设：最近 24 小时、7 天、30 天。
- 开始时间/结束时间：通过时间组件选择，不需要手动输入自然语言。
- 排序：风险等级、发生时间、影响范围。
- 字段搜索：按事件、等级、对象等表格字段搜索。

## 智能分析

### 模型配置

进入“智能分析 / 模型配置”后，可新增或编辑：

- 配置名称。
- 厂商。
- 模型名称。
- 接口 URL。
- API Key。

API Key 在接口返回时会脱敏展示。

### 分析配置

进入“智能分析 / 分析配置”后：

- 可选择一个或多个业务。
- 可选择多个分析字段。
- 可填写组合字段，例如 `等级 + 归属对象 + 时间`。
- 可选择按业务分别分析、多业务合并分析或多业务对比分析。
- 可选择输出格式并修改提示词模板。

## 智能搜索

维护知识源名称和路径后，输入问题并提交。当前后端会返回模拟问答结果，包含行动建议和引用来源。

## 验证命令

```powershell
npm.cmd run check
npm.cmd run api:smoke
npm.cmd run cleaning:e2e
npm.cmd run port:check
```

`api:smoke` 覆盖主要 API、模型配置和组合分析；`cleaning:e2e` 覆盖数据清洗主流程。
