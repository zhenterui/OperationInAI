Quick Guide

使用说明

按业务流使用
1. 看态势 态势总览会根据已配置业务、业务流、数据源、规则和业务数据自动生成指标、流程和风险信号。
2. 配业务流 进入数据清洗，先配置数据源和认证，再配置字段映射与清洗规则，最后在业务配置中编排串行、并行和条件分支节点。
3. 查业务数据 进入数据展示，选择业务模型、时间字段、时间预设或自定义时间组件，再按风险、时间或影响范围排序。
4. 做智能分析 进入智能分析，先在模型配置页签维护厂商、URL、模型和 API Key，再选择一个或多个业务与字段生成分析。
5. 问知识库 进入智能搜索，配置 URL 或本地路径知识源后，通过问题输入触发关键词匹配和提示词回答。

Expression Guide

表达式速查

过滤条件 / 清洗规则
过滤条件怎么写 先用响应数据路径定位记录集合，例如 data.items[] 或 data.metrics[]，再写条件：level in [P0,P1] && duration > 300。 支持 ==、!=、>、>=、<、<=、contains、in [a,b]、exists，并支持 && 和 ||。 嵌套数组可写 data.metrics[].name == cpu && value >= 90，[] 表示数组任意元素。
清洗规则怎么写 规则表达式格式为 源字段 -> 目标字段 | 动作(参数)。目标字段为空时，默认覆盖原字段。 常用动作：trim、lower、upper、enum、default、filter、date、number、enrich。 示例：level -> severity | enum(P0=高,P1=中,P2=低)，owner -> owner | default(未分配)。
